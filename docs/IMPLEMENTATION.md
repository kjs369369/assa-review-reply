# 첫 앱 구현 기준

최신 배포 구조: GitHub Pages 정적 앱. 입력 리뷰는 브라우저에서만 처리하며 서버로 보내지 않는다. 자세한 현재 구성은 README.md와 DEPLOYMENT.md를 따른다. 아래 내용은 단계별 구현 기록이다.

## 최신 변경 — 코드 없이 바로 이용 (2026-09-26)

사용자 요청에 따라 이번 리뷰 앱은 공개 접근으로 변경했다. 첫 화면을 감사 인사·앱 목적·3단계 사용법으로 바꾸고 코드 입력과 잠그기를 제거했다. 서버도 공개 접근을 허용하며 신규 세션 쿠키를 발급하지 않는다. 기존 인증 모듈은 향후 별도 보호 앱을 위해 유지한다. 아래 초기 구현의 코드·세션 설명은 보호 모드의 이력이며 현재 리뷰 앱의 접근 정책이 아니다.

첨부 DESIGN-ferrari.md는 디자인 참고자료로 사용했다. 차콜 #181818, 흰색, 레드 #da291c를 적용하고, 한글 시스템 글꼴과 읽기 쉬운 흰색 작업 영역을 유지했다. 자동차 이미지·브랜드 로고·전용 유료 글꼴은 사용하지 않았다. 푸터: AICLab · AI콘텐츠융합연구소 · 대표 김진수 / info@aiclab2020.com.

검증: 자동 검사 9개 통과. 새 쿠키 없는 상태에서 즉시 답글 3종 생성, 코드 입력란 0개, 신규 쿠키 0개, 320·390·768·1365px 가로 넘침 없음 확인. 공개 접근에서도 Origin 검사·입력 검증·요청 제한을 유지하고 테스트했다. 현재도 로컬 버전이며 외부 배포 점검은 미완료다.

## 결정과 범위

- 앱별 코드로 독립 접근한다. 도구함 가입이나 전 앱 공통 코드를 요구하지 않는다.
- 책 이외의 강의·이벤트 링크도 같은 앱을 이용할 수 있다. 채널 값은 안내 문구만 바꾼다.
- 유료 AI API를 호출하지 않는다. 이번 결과는 문장 조합형 첫 구현이다.
- `APP_CODE`는 해당 앱의 접근 코드, `SESSION_SECRET`은 서버의 서명 비밀이다. 역할이 서로 다르다.
- 세션의 appId, role, expiry, 코드 버전 서명을 모두 검증한다. 관리자 공개 경로는 만들지 않는다.
- 코드 변경은 해당 앱의 기존 세션을 무효화한다. 이미 인쇄된 코드를 변경하기 전 대체 안내를 마련해야 한다.
- 코드 공유를 막는 결제 인증은 아니다. 코드 보유자 이용 방식이다.
- 신규 앱 등록은 서버 설정과 화면 경로·기능을 함께 추가해야 한다.

## 화면 설계

색: 잎색 #08775D, 깊은 녹색 #173C35, 흰색 #FFFFFF, 옅은 회녹색 #F3F8F6, 연두 #E6F5BD.
글꼴: 기기에 설치된 Apple SD Gothic Neo / Malgun Gothic. 외부 폰트 요청 없이 한글 가독성 확보.
레이아웃: 데스크톱은 입력과 결과를 좌우로, 모바일은 입력 다음 결과를 세로로 배치. 본문 왼쪽 정렬.

```
로고                                      이용 상태
짧은 리뷰, 다정한 답글.                    80자
[리뷰·유형·메뉴·말투] | [감사 / 메뉴 / 방문 인사]
[만들기]              | [복사 / 다른 표현 / AI 요청문]
                 결과 뒤 다음 학습 안내
```

통계 대시보드나 홍보용 카드 목록 대신 실제 답글 작업이 첫 화면의 중심이다. 이용코드 화면에는 복잡한 가입 절차를 두지 않는다. AI 미연결을 시연 결과로 숨기지 않고 ‘무료 문장 조합 도구’로 표시한다.

## 확인 결과

- 자동 검사 8개 통과. 그중 72가지 유형·말투·변형·메뉴 조합 전수 검사 포함.
- 잘못된 코드 차단, 실제 코드 입장, 답글 3개, 메뉴 적용, 불만 분기 확인.
- 클립보드 내용 실제 읽기로 복사 결과 확인. 권한 거부 시 직접 복사 입력칸 확인.
- 입력 변경 시 복사 잠금, 다른 표현 순환, 새로고침 후 리뷰 삭제·세션 유지 확인.
- 잠그기 후 새로고침 시 코드 입력으로 복귀 확인.
- 320 / 390 / 768 / 1365px 화면에서 가로 넘침 없음.
- 메뉴의 HTML 태그를 텍스트로 표시하고 실제 요소를 만들지 않는 것 확인.
- 강의 채널의 안내 문구 변경 확인.
- 캡처는 실제 로컬 실행본. 공개 서비스·최종 원고 이미지와 구분.

## 다음 구현 단계

1. 사용자 화면·문구 검토를 반영한다.
2. 무료 배포 계정·권한·한도를 확인하고 서버 어댑터를 선택한다.
3. 공용 환경의 요청 제한·HTTPS·보안 설정을 검증한다.
4. 공개 주소를 검증한 뒤 QR과 원고 캡처를 확정한다.
5. 실제 AI 생성은 무료 한도·한국어 품질 검증을 거친 별도 기능으로 추가한다.
